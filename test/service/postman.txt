✅ Módulo Categoría
1. Cargar categoría
Método: GET

URL: http://localhost/lab_prog_2025_titos_alan/public/categoria/load/1

Esperado: Retorna la categoría con ID 1.

2. Crear categoría
Método: POST

URL: http://localhost/lab_prog_2025_titos_alan/public/categoria/save

Body (JSON):

json
Copiar
Editar
{
  "nombre": "Guantes de Box"
}
3. Actualizar categoría
Método: PUT

URL: http://localhost/lab_prog_2025_titos_alan/public/categoria/update

Body (JSON):

json
Copiar
Editar
{
  "id": 1,
  "nombre": "Guantes de MMA"
}
4. Eliminar categoría
Método: DELETE

URL: http://localhost/lab_prog_2025_titos_alan/public/categoria/delete

Body (JSON):

json
Copiar
Editar
{
  "id": 1
}
5. Listar categorías
Método: GET

URL:
http://localhost/lab_prog_2025_titos_alan/public/categoria/list?limit=10&offset=0&nombre=gua
